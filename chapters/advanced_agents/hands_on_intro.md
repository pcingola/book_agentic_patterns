## Hands-On: Introduction

The hands-on sections that follow demonstrate three adversarial agent patterns using the `DebateOrchestrator` and `RedTeamAgent` classes from `agentic_patterns.core.agents`.

The first exercise (`example_debate.ipynb`) walks through the full debate lifecycle: running a basic advocate-vs-critic debate, customizing it with persona prompts to simulate different domain viewpoints, and then applying red-team analysis to the resulting verdict to surface any remaining risks.

The second exercise (`example_deep_research.ipynb`) builds a deep research agent that decomposes a broad question into sub-queries, retrieves evidence from multiple sources, and synthesises a structured report with references.

The third exercise (`example_rubric.ipynb`) uses a rubric agent to evaluate a piece of work against explicit criteria, producing scored assessments with evidence and actionable feedback.
